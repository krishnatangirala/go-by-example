# go-by-example
GoLang Examples README

Examples are from this link: https://gobyexample.com/

You don’t need to install Go to try these examples. Just follow the instructions below to execute my examples

▶️ Open the [Go Playground](https://go.dev/play/) to run my examples online.
(Hosted by the official Go team)

1. Navigate to the example folder (for e.g., ex-01-hello-world points to [Hello World Example](https://gobyexample.com/hello-world)) 
2. Copy the contents of the *.go file
3. Paste the contents in the Go Playground and Hit 'Run'
